# Chronicle Class & Hero Blueprints

Inserisci in questa cartella (`public/blueprints/`) i tuoi disegni tecnici widescreen (16:9) o le tue tavole in formato **WebP** (`.webp`):

### 1. Formato Widescreen 16:9 WebP
* **Formato:** `.webp` (garantisce massima compressione e risparmio spazio mantenendo alta qualità)
* **Proporzioni:** Widescreen 16:9 (es. `1920x1080` o `1280x720`)
* **Stile grafico:** Tratteggio a china bianca, dorata o ciano su fondo pergamena scura / antracite / trasparente, con quote geometriche, rune e schemi anatomici.
